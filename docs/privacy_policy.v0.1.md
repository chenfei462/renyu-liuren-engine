# 隐私政策 v0.1

壬语 MVP 仅用于传统文化学习与娱乐体验。浏览器麦克风权限只用于当前语音会话，不保存用户录音。

## 数据使用

- 本地服务可能记录课式 ID、模式、问题分类、安全状态、反馈类型、备注和时间戳。
- 这些记录仅用于测试、质量复盘、安全拦截评估和产品改进。
- 不保存 OpenAI API key、浏览器录音、原始音频文件或支付信息。

## 删除请求

测试用户可以提供测试编号、课式 ID 或反馈令牌，请求删除对应本地反馈记录。当前 MVP 不含账号系统，因此删除范围以本地反馈日志可定位的信息为准。

## 第三方服务

Realtime 语音能力需要服务端调用 OpenAI Realtime API。标准 API key 只在服务端读取，不返回浏览器。
