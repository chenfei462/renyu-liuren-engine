# 第 6 阶段 Beta 准入报告 v0.1

## 结论

当前系统可以进入 **受限 Beta**，但不能开放完整占断能力。

受限 Beta 只允许学习、娱乐、合作/谋望等低风险问题。医疗、法律、投资、人身安全、隐私窥探、感情操控、应期承诺和未审校复杂规则仍需阻断或安全降级。

## 已通过

- 排盘引擎、知识库、解释器和娱乐化玩法保留原有回归测试。
- 解释器输出新增 `safety_validation`、`beta_readiness_flags`、`blocked_reasons`。
- 高风险类别继续触发 `safety_only`。
- 故事版和导师版不能绕过高风险降级。
- Realtime 提示词要求检查 `safety_validation` 和 `blocked_reasons`。
- 红队样例覆盖高风险、隐私、操控、绕过安全、伪造出处和模型自行排盘。

## 阻断项

| 类型 | 状态 | 处理 |
|---|---|---|
| 专家审校 | 存在待审规则 | 比用、涉害、遥克、昴星、八专、别责、伏吟、返吟不得作为完整断法进入 Beta |
| 版权 | 存在 blocked 内容 | 现代出版物、课程资料、论坛长文正文不得入库或展示 |
| 高风险 | 永久安全降级 | 医疗、法律、投资、人身安全只输出提醒和专业求助建议 |
| 迷信化 | 继续限制 | 不输出应期承诺、胜率、保证、神煞单独结论 |
| 外部模型 | 需人工验收 | Realtime 真实语音仍需带 API key 做人工红队 |

## Beta 允许范围

- 学习卡和导师解释。
- 十二天将故事版娱乐表达。
- 专业版出处卡展示。
- 本地分享报告。
- 低风险问题的文化解释和反思提示。

## Beta 禁止范围

- 医疗诊断、用药、手术判断。
- 法律策略、胜诉预测。
- 投资买卖、收益、时机建议。
- 人身安全处置、报警替代建议。
- 侵犯隐私、跟踪定位、操控关系。
- 未审校九宗规则完整断语。

## 第 7 阶段进入条件

- 全量测试通过。
- 红队测试通过。
- 受限 Beta 范围写入产品开场和分享报告。
- 用户反馈入口记录安全误触发和漏拦截样例。
