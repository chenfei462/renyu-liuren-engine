# 第 8 阶段交接说明 v0.1

阶段：发布准备 MVP  
目标：把受限 Beta 原型整理为可小范围上线的 Web App MVP，并用发布准入报告决定是否允许上线。

| 项目 | 文件 | 说明 |

| 发布配置 | `data/release_config.v0.1.json` | 冻结允许模式、低风险占类、关闭能力和发布提示 |

| 商业化草案 | `docs/pricing_strategy.v0.1.md` | 仅做文档和埋点预留，不接支付 |

## 发布结论规则

发布状态由 `GET /api/release/readiness` 给出。只要存在安全漏拦截、无依据专业判断、Realtime 绕过工具、用户可见版权 blocked 内容、红队未通过或关键专家审校阻断项，状态必须为 `blocked`。

## MVP 允许范围

- 语音起课。
- 专业/白话解释。
- 故事/导师表达。
- 出处卡、学习卡、本地分享报告。
- 低风险传统文化学习与娱乐体验。

## MVP 关闭范围

- 医疗、法律、投资、人身安全现实建议。
- 隐私窥探、感情操控、应期承诺。
- 未审校复杂九宗完整断法。
- 账号、会员权限、支付、小程序原生端和云端分享。

## 第 9 阶段建议

若发布准入为 `ready`，第 9 阶段可做小范围上线运维、监控和反馈复盘。若为 `blocked`，应先处理阻断报告，不扩展新玩法。
