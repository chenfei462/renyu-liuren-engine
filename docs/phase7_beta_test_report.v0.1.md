# 第 7 阶段 Beta 测试报告 v0.1

## 当前结论

系统已具备受限 Beta 的本地技术闭环：范围控制、反馈记录、报告聚合、前端反馈入口和 Realtime 受限提示均已接入。

本报告为测试前初版，真实用户数据以 `/api/beta/report` 聚合结果为准。

## 当前配置

- Beta 配置：`data/beta_config.v0.1.json`
- 反馈日志：`data/beta_feedback.v0.1.jsonl`
- 报告接口：`GET /api/beta/report`
- 反馈接口：`POST /api/beta/feedback`

## 自动验收项

- Beta 配置只允许四种已实现模式。
- 医疗、法律、投资、人身安全继续降级。
- 安全阻断原因非空时不进入正常 Beta 解释。
- 反馈写入本地 JSONL，并剔除录音和密钥类字段。
- 报告可统计反馈数、会话数、安全拦截数和人工复核样例。
- 前端显示受限 Beta 标识、测试编号、反馈面板和安全状态。
- 分享报告包含受限 Beta 与文化娱乐免责声明。

## 受邀用户测试脚本

1. 低风险合作/谋望问题：完成一次语音提问，查看专业或白话解释。
2. 模式切换：追问“讲故事版”或“讲导师版”，确认仍基于同一课式和出处。
3. 高风险降级：提出医疗、法律、投资或人身安全问题，确认只返回安全提醒。
4. 提交反馈：选择一个反馈类型并填写备注。

## 复核清单来源

以下情况会进入人工复核：

- `blocked_reasons` 非空。
- 反馈类型为 `source_insufficient`、`safety_issue` 或 `chart_question`。
- 高风险类别触发 `safety_only`。
- 语音体验问题导致工具调用失败或会话中断。

## 发布准备建议

第 8 阶段不应扩展新占类或新玩法，应先根据真实 Beta 报告处理安全漏拦截、出处不足、解释难懂和语音稳定性问题。
