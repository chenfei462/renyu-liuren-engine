# 壬语第 1 阶段资料包

版本：v0.1  
阶段：典籍与规则调研  
日期：2026-04-30  
范围：只做结构化资料准备，不实现排盘引擎、语音、前端或数据库。

## 文件清单

- `data/classic_source_cards.v0.1.md`：六本指定典籍资料卡。
- `data/glossary.v0.1.md`：核心术语表。
- `data/question_categories.v0.1.md`：用户问题分类表。
- `data/rule_versions.v0.1.md`：规则版本与流派差异表。
- `data/rule_source_cards.v0.1.md`：规则/出处卡，当前 112 条。
- `data/not_for_launch.v0.1.md`：不可上线内容清单。
- `docs/phase1_handoff.v0.1.md`：阶段验收与第 2 阶段交接说明。

## 使用原则

- 所有古籍内容先按“定位、摘要、规则化转写”进入资料库；正式上线前再做版权与版本审查。
- 每条解释必须区分“直接依据、现代转述、产品化推论、娱乐表达”。
- 涉及医疗、法律、投资、人身安全、重大婚姻决策的问题，默认进入安全降级，不输出确定性建议。
- 第 2 阶段排盘引擎只能使用本包中标记为“可进入 MVP”的规则。
